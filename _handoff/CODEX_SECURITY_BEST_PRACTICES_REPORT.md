## فحوصات سلبية

- لم يظهر استخدام `dangerouslySetInnerHTML` أو `eval` أو `new Function` أو تعيين `innerHTML` في أسطح التطبيق.
- لم تظهر أسرار ثابتة أو private keys أو JWT حقيقية ضمن الملفات المتتبعة؛ ملف البيئة المتعقب الوحيد `.env.example`.
- لا تُخزن جلسة الموبايل أو رمز push في AsyncStorage؛ استخدامه المتبقي محصور في بيانات غير سرية مثل سلة الضيف وحالة onboarding.
- جميع جداول التطبيق التي جُردت في الجولة السابقة لديها RLS؛ يلزم إثبات ذلك مجدداً بعد تطبيق الهجرات على staging.
- هذه النتائج ليست false positives معروفة. البنود المفتوحة أعلاه مخاطر تشغيلية فعلية، لكنها ليست دليلاً على اختراق قائم.
